# 当前能力地图与参考项目对照

2026-10-21 固定基线见 [证据索引](EVIDENCE_INDEX.md)。结论：当前已形成知识问答/只读任务的可恢复主链路；接下来最应深化质量评测、资料生命周期和知识运营，不宜复制全部参考服务。实施保持暂停。

## Current Capability Overview

成熟度只评价表中明确的业务范围：`ABSENT` 未实现；`BASIC` 有基本链路；`PARTIAL` 有多项能力但关键场景不全；`MATURE` 在限定范围内有完整实现及匹配验证，**不代表生产认证**。参考项目同时标出条件，不作两个系统的加权总分。

当前结构：六个 Maven 模块承载契约/安全/知识/任务/会话/网关，Python 承载三框架 AI 运行，React 独立仓库。参考为更广的 Java 服务群、Vue 工作台及外部 AgentScope 路由。模块更多并不自动意味着实现更好。[E01](EVIDENCE_INDEX.md)

## Capability Maturity Summary

成熟部分集中在当前有限范围的**可信状态和可靠执行**；不足主要集中在**资料管理、质量运营、复杂输入、团队使用和持续交付**。这说明应沿真实用户任务深化，不能用增加框架组件或通过更多相似测试代替业务补全。各项事实路径见 [EVIDENCE_INDEX](EVIDENCE_INDEX.md)，建议优先级见 [OPPORTUNITIES](OPPORTUNITIES.md)。
