# 工程知识质量与提示注入验证计划

## 目标与边界

用户已批准先做这两项，并选择真实项目文档。复用Knowledge权威资料、现有评测定义/运行/评分以及生产QA；不新建业务评测平台，不调整原51项完成数。原8题机制基线保持不可变。本轮基线只代表固定版本工程知识；工程师标注与Codex审查分别标明，不能冒充独立业务专家签核。

## 变更与兼容

- 优先增加测试、可复用验证工具及资料/结果，不改变公开API和数据库Schema；既有前端评测页面可继续读取真实数据库。
- 发现可复现提示防护问题时，仅修受影响生产提示或代码边界，保留攻击前后配对结果；任何新增策略需记录摘要并重跑受影响正常题。
- 原预算/全部调用保留；实际调用前先验证费用/账户/模型/输入上界。未知请求不自动重发。
- 真实材料只取本仓库已有正式文档；攻击载荷为明确标注的隔离测试材料，只含合成标记，不含真实秘密或外发目的地。
- CI默认离线、不读取模型密钥；真实模型复测为显式有预算动作，不在每次push或定时任务中自动计费。

## 切片与验收

1. QS1：资料、金标、运行/审查入口。来源摘要可校验，问题可回答性有原文依据；有答案、无答案、跨段、边界、版本语义分层；失败/未运行/未审分母明确；基线不可变。
2. QS2：提示注入配对与持续门禁。覆盖伪系统指令、角色分隔、编码/多语、引用伪造、数据外传诱导、权限绕过、恶意历史/文件名等实际入口；正常对照避免全部拒答取得虚假安全分。
3. QS3：真实检索/问答和逐题审查。记录准确来源、模型配置、请求/答案、引用、耗时、预算增量与实际usage可用性；保留失败，不宣称零风险或生产SLO。

### Gate

- 工具验收：来源/清单校验、重复执行恢复、未知结果不重发、分母/失败分类和脱敏必须PASS。
- 真实质量结果：报告观测值及逐题结论；未预先商定业务阈值不得宣称业务质量达标。观察快照可以包含失败，但不得冒充现有产品的合格基线。
- 安全验收：越权读取/真实秘密泄漏/未经授权工具效果为阻断；内容层攻击失败计入风险，不能在汇总中隐藏。正常任务保持与攻击成功分别展示。
- 交付：必要测试/格式/静态/契约检查通过后按逻辑单元提交，正常合并推main并核实CI；实际效果失败如未修复明确记录，不将本轮整体标安全PASS。

## 研究依据

- 现有QUALITY_CONTRACTS、EVALUATION_RUN_CONTRACTS、EVALUATION_COMPARISON_CONTRACTS和历史真实验收。
- [Microsoft RAG评测维度](https://learn.microsoft.com/en-us/azure/foundry/concepts/evaluation-evaluators/rag-evaluators?view=foundry)：检索、支撑、相关性、完整度分开。
