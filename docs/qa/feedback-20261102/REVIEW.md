# S14A 实施审查

当前范围无未解决阻断项；实现与验收按 operations-feedback-v1 核对。

- 权限：收件人由资料行确定；SQL强制tenant+owner/reporter，正文读取再次走现时完整发布授权；任务记录不会因反馈向其他owner开放。公共POST只需read，owner编辑/发布尚不在本片。
- 证明：Tasks成功终态实际结果引用与K08可见性同时校验；RS256签名复用受控材料但独立audience/purpose，60秒/零宽限，Knowledge绑定caller/task/引用摘要后仍重验资料ACL。证明不存库、不写日志，不能代替HTTP身份。
- 数据：V14表/全部字段注释、原键唯一约束、收发分页索引；锁资料后检查幂等与当前完整引用，READ_COMMITTED/5秒短事务；IAM/远程核验在事务外，唯一冲突退出事务再读回执。无新中间件/依赖，手写SQL仅Mapper XML。
- 恢复：原key回执优先于功能/权限变化，新请求仍拒绝；前端只存摘要/编号，收据内容不符不清键，原子确认不创建幽灵待提交。原文不可读或开关关闭时仍可从资料反馈页恢复。
- 隐私与UI：不自动复制答案/研究正文；owner不取得他人taskId，列表/详情保持反馈记录与原文权限分离。消息校验、动态加载失败及窄屏均有实际验证。回列表保留scope/cursor。
- Runtime：默认关闭，显式开关纳入Docker快照选项；未执行新部署。IAM与SQL之间无分布式原子快照，保留既有每边界重验限制。

代码卫生的短事务/数字建议已分类：协议上限均为FeedbackProtocol常量；测试启动/HTTP/退出期限只是有界夹具，不是业务配置。Java缺少独立格式器为既有工具限制，不新增格式化依赖。测试与视觉失败的修复证据见TEST_RESULT。
