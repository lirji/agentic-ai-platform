# S12A 审查

2026-11-01，当前实现审查无阻断项。范围为核心提交41564e6及同任务未提交的页面、路由、联合验证；同Agent独立审查步骤。

| 失败场景 | 核对结论与证据 |
|---|---|
| 改写覆盖原问题或引入外部资料 | Conversation保存原输入；query.originalQuestion由Tasks/Python/前端三端绑定。改写只产生检索字符串，owner/范围/策略保持原值。共享金标及非法变体覆盖。 |
| 历史答案失权或递归依赖被截断 | prepare_query/恢复/提交前重验完整身份；全部依赖去重上限10，不能截断。PG失权、取消与Tasks持久测试通过。 |
| 模型超时、预算不足被混为正常成功 | 仅约定可回退错误使用原问题；取消/配置/费用/权限仍失败。至多一次改写且有5秒界限，原累计账本保留。 |
| 未知受理刷新后改换路由/前文/策略 | sessionStorage只保存摘要与非正文快照；重试保留版本、修订、policy、前文和原键；变更正文/范围须通过摘要核对。生产构建浏览器覆盖能力关闭和修订前进。 |
| 新图破坏旧快照或门禁关闭导致在途丢失 | v1/v2/v3分离；幂等先查已受理记录，新开关默认false。恢复与重放测试通过；回退兼容边界已写契约。 |
| 公开代理签错服务受众或开放内部接口 | v3仅新增会话turns、能力GET；JWT交换映射会话受众；开发桥保持方法/UUID白名单，容器断网9路由smoke通过。 |
| 模型质量结论越过证据 | 固定3题分别列改善/不变/退化，明确9份合成资料与资料组指标；无新增答案生成，不宣称支撑度或生产质量。 |

Java格式器缺失、旧警告、真实精排和生产部署未验证均保留于[验收结果](TEST_RESULT.md)。没有用测试数量替代业务验收，也没有改验收要求迁就当前实现。
