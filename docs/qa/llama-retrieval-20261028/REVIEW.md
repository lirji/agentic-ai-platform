# S11C 审查

源码/离线验证与固定容器验收PASS；同一执行者分阶段审查，不宣称独立Agent认证。

- 权威边界：客户端固定可信身份和两个路由；输入不提供tenant/owner/URL。响应拒绝重复/未知/snake_case字段、无效score、摘要、范围、跨源身份/正文漂移。最终解析比较数量/顺序/完整身份/正文/来源；失效不返回半列表或缓存结果。
- 算法：一次Embedding、候选原语一次请求、一次原生RRF；保持原一基排名空位与VECTOR→KEYWORD运算顺序，同分按chunkId；原score独立保留。完整元组节点ID避免正文hash合并；共享金标同时运行旧Java实际搜索和Python原生Retriever。
- 框架：不使用默认QueryFusionRetriever，不读取Settings或解析默认LLM。构造守卫在使用前移除，残留时失败关闭；只隔离本模块的dispatcher。原生异步入口不调用基类全局内容事件分发；不建立线程桥接、同步循环或第二张任务图。
- 时间/容量：共享应用容量显式注入，2在途即时拒绝，无等待队列；一次30秒总预算夹紧根期限，各阶段10/12/5秒夹紧剩余预算，包含客户端完整读取。取消释放许可并停止后续，HTTP不自动重试。消费者S11E须在应用范围共享同一个容量对象。
- 数据/费用：输出JSON模型，节点与客户端不写检查点；Embedding使用既有端口与预算适配，真实调用装配仍由S11E负责。当前测试全部用协议向量，不声称语义质量或付费端到端效果；无Reranker、额度扩充、DDL/新依赖/写工具。

边界：新用例尚未接入旧公开搜索/任务消费者，属于本片明确范围。内部原始排名/贡献不得直接作为公共诊断，脱敏与策略持久化归S11E。52项需显式启用的环境集成默认跳过不算PASS，其中本片新只读集成将单独显式执行。
