# S11D 审查

源码/离线及固定容器协议验证PASS；同一执行者分阶段审查，无独立Agent。

- 授权与外发：身份仍固定在Knowledge客户端，候选完整身份保留；外发前解析50项内全列表，最终输出再解析。任何一步失效整次失败；模型仅见query与正文，不见tenant/owner/资料ID/存储地址。
- 协议与证据：评分索引严格整数、全覆盖、唯一且不越界；分数有限且在已核验协议0–1范围。重复键/错误形状/错误模型/返回原文/异常usage/超限正文失败关闭。原始模型正文不能成为权威。RRF与精排分数独立，输出JSON明确RERANKED或EMPTY。
- 预算与未知：独立配置指纹和账本scope拒绝挪用旧预算；文件权限、nofollow、锁、累计总和及先行fsync验证。专用执行器单在途，无无界队列；取消期间落盘许可保留，之后不发送模型。预留是保守上界，非提供方账单；未知HTTP结果不退款、不重试。
- 期限与框架：Embedding/候选/解析/重排都夹紧到同一根期限；模型最多5秒，容量与RRF共享。原生异步后处理显式隔离Settings/global_handler/全局事件，不使用默认to_thread桥接。失败不会被换成RRF成功。
- 兼容与范围：RRF默认策略和历史消费者保留，只有精排请求使用候选目标50。无DDL/新依赖/新服务、无前端或旧账本变更；消费者与检查点策略落盘归S11E。
