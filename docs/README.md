## 状态约定

- **已确认要求**：用户明确提出的目标与交付范围。
- **仓库事实**：有固定提交、配置或源码依据的现有实现；不自动代表部署环境实际启用。
- **建议方案**：架构、技术选型或可行性分析中的工程判断，尚不视为完整批准设计或实施授权。
- **验证通过**：必须标明验证对象与范围；文档检查通过不表示业务、性能或安全验收通过。
- **待验证/待明确**：保留未解决的问题，后续按实际证据更新。

当前目标设计以架构与选型正文为准；可行性分析保留前期背景和当时的验证状态，顶部链接指向后续设计。索引和进度文件只保存入口与状态。尚无新项目的已实现架构、运行环境、数据库实例、连接凭据、正式 API 契约或部署手册，不建立空白占位文档。
