## 数值口径样例

| 输入 | 预期 |
| --- | --- |
| ANSWERABLE，金标 A(2)、B(1)，R=[X,A,B]，K=2 | Recall=1/2；MRR=1/2；nDCG=(3/log2(3))/(3+1/log2(3)) |
| 相同金标，R=[] | Recall/MRR/nDCG 均为 0，执行可成功 |
| 相同金标，R=[A,A,B] | 按稳定身份去重为 [A,B] 后计分，不能重复累计命中 |
| NO_ANSWER，返回 []，回答依据不足 | 召回三项为 null，不进分母；人工拒答评分可 PASS |
| NO_ANSWER，引用真实但无关块并编造金额 | 引用可访问可 PASS；支撑及拒答 FAIL |
| 超时或权限失效 | 执行失败/失效，质量字段 null；失败数增加，不伪装成空命中成功 |
| 旧/新分块 ID 全变但原文相同 | 先按 sourceHash/来源位置映射，无法映射则不可比较 |
